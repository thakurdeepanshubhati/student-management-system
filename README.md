# Student Management System

## Project Description

Student Management System is a simple frontend project developed to manage basic student records.

The project allows the user to:

* Add a new student
* Delete a student
* Search for a student by name
* View total number of students
* View student details in a table

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

### 1. Student Registration

The user can enter:

* Student ID
* Student Name
* Email
* Course
* Semester

### 2. Add Student

After entering the details, the user can click the **Add Student** button to add the student to the records table.

### 3. Delete Student

Each student record has a **Delete** button which removes that student from the table.

### 4. Search Student

The search box allows the user to search for a student by name.

### 5. Total Students

The system automatically displays the total number of students in the table.

## Project Files

* `index.html`
* `README.md`

## How to Run

1. Download or copy the project.
2. Open the `index.html` file.
3. The Student Management System will open in the web browser.
4. Enter student details and use the available options.
